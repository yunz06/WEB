
# NEWS HUB

Website đọc và quản lý tin tức trực tuyến.

## Technologies

- PHP 8.x
- MySQL 8.x
- Bootstrap 5
- HTML5 / CSS3 / JavaScript
- MVC Architecture
- PDO

## User Features

- View news
- View categories
- Search articles
- Register / Login / Logout
- Comment on articles

## Admin Features

- Dashboard
- Article CRUD
- Category CRUD
- User management
- Comment management
- Multiple image upload
- Rich Text Editor
- Pagination

## Installation

1. Clone repository.
2. Create MySQL database.
3. Import `database/news_hub.sql`.
4. Configure `config/database.php`.
5. Run project using Apache/PHP server.
